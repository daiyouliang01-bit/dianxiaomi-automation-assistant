# 店小秘自动化工具 V2

这是面向速卖通店小秘日常发品流程的 Chrome 插件交付包。V2 继承 V1 的全部业务功能，重点优化目录结构、交付文档、RPA 失败处理和维护边界。

## 加载方式

1. 打开 Chrome 扩展管理页：`chrome://extensions/`
2. 开启右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目根目录（包含 `manifest.json` 的目录）。

## 功能范围

- 同步店小秘违禁词库
- 配置 Gemini API Key
- 配置通义千问 API Key
- 汽摩配品牌词库维护
- 单品 AI 标题优化
- 批量标题优化
- 批量产品编码优化
- 安全检测
- 单品一键优化
- 汽摩配模式一键优化
- 医疗店铺模式：无电源插头属性恢复
- 采集箱 RPA 流水线
- 图片空间不足时自动清理图片空间

## V2 保持不变的关键行为

- 店小秘页面里的按钮位置和按钮文案保持 V1 习惯。
- 批量标题优化仍按“产品标题”列定位并在单元格内写入。
- 普通产品标题优化直接写回纯标题文本；`90-128` 字符只是软目标，不为了凑长度强行加泛词，超过 `128` 字符会兜底压缩。
- 汽摩配标题优化只从原标题中提取真实存在的信息，按“核心工艺 + 产品词 + 关键规格 + 外观描述 + 车型/年份/OE + for 品牌”重组，不接入搜索词或市场排序逻辑。
- 汽摩配标题只有在原文出现 `for`、`fit for`、`suitable for`、`compatible with`、`adaptation for` 等适配语境时，才把整车品牌保留为 `for 品牌`。
- 汽摩配标题最前面的厂牌、工厂名、供应商名、系列名会按风险词删除，不自动改成 `for 品牌`。
- 汽摩配标题有质量门禁：AI 输出过短、畸形、丢失关键规格/适配品牌，或新增原标题没有的品牌、敏感规格、低价值扩写时，会改用本地兜底重组结果，避免坏标题直接写回。
- 批量标题采集会过滤 `100/128` 这类字数计数器，避免把编辑态 UI 文本写回标题栏。
- 产品编码优化仍使用 `productKey + variantKey + originalCode` 稳定身份匹配，不能按行号硬写。
- 产品编码已是英文/数字/允许符号且不超过 19 字符时保持不动，包括英寸双引号 `"`；中文材质编码会优先本地处理为“型号 + 材质缩写 + 规格”。
- 医疗店铺模式会在点击 `Type-C/No Plug / 无电源插头` 前记录客户已填写的零售价、货值、库存、扣减方式、重量、包装尺寸、物流属性和商品编码；点击后重新回填这些信息。
- 医疗店铺模式中“是否原箱”固定恢复为 `是`，发货期限和产品有效期不处理。
- 医疗店铺模式会打开物流属性弹窗读取客户原先勾选的选项，并在回填时按原选项恢复；读取或校验失败时不继续保存，转人工处理。
- RPA 仍在批量标题优化和产品编码优化完成后由员工手动启动。
- RPA 启动后会锁定当前选中的具体店铺账号；启动页签作为专用运行页继续处理该店铺。
- RPA 启动后先在当前运行页进入图片管理，检查并清理图片空间到 `50M` 以上；预检完成返回采集箱并准备派发队列时，才自动打开新的前台工作页。
- 员工可以在新页切换其他店铺，不影响专用运行页继续跑原店铺。
- 如果专用运行页本身被切到其他店铺或“全部”，RPA 会自动停止，避免误处理其他店铺产品。
- RPA 失败产品只记录并跳过，本轮不反复打开。
- RPA 完成后弹出简单总结：成功多少条、失败多少条。
- 图片空间清理保持 50M 阈值。
- 图片空间清理先选择 `100条/页`，翻到最后一页，再从 `最后页 - 2` 开始删除。例如最后页是 869 页，则从 867 页开始删。
- 每轮 RPA 使用独立 `runId`；后台持久化登记自动打开的编辑标签，Service Worker 重启后会核对并恢复登记，不接管人工打开的编辑页。
- 翻译、图片处理和详情清理任一关键阶段未确认成功时，保存门禁会阻止自动保存并转人工复核。
- 标题和商品编码使用千问；Gemini 仅用于现有的属性压缩和图片内容分析。
- 图片内容分析需要读取商品详情中的外部 HTTPS 图片，因此扩展具有 HTTPS 图片读取权限；后台会拒绝本机/内网地址、非图片响应、超过 `5MB` 的单图，并将单批限制为 `30` 张。

## 目录结构

```text
店小秘自动化工具/
  manifest.json
  popup.html
  style.css
  src/
    background/       Chrome 后台、AI 调用、标签页管理
    config/           页面文案和选择器配置
    content/          页面入口和按钮注入
    domain/           SKU 映射、汽摩配品牌规则
    page-adapters/    店小秘页面识别和采集箱判断
    platform/         通用 DOM 工具和注入钩子
    popup/            插件弹窗逻辑
    safety/           RPA 保存、图片空间和删图安全规则
    state/            RPA 运行状态和汇总
    workflows/        RPA 与图片空间清理流程
  tests/              Node 内置测试
```
